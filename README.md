# LiveBot — 抖音直播AI助手

抖音直播间自动点赞 + 智能评论 Chrome 扩展，支持免费/会员双版本。

## 功能

| 功能 | 免费版 | VIP版 |
|------|--------|-------|
| 自动点赞（频率可调） | ✅ | ✅ |
| 模板自动评论 | 60秒固定，1条 | 间隔可调，最多50条 |
| AI 智能评论（DeepSeek） | ❌ | ✅ |
| 自定义 AI 人设/Prompt | ❌ | ✅ |
| Shadow DOM 侧边栏面板 | ✅ | ✅ |
| 操作日志 + 统计 | ✅ | ✅ |
| 反检测 | ✅ | ✅ |

## 安装

1. 下载扩展文件夹
2. Chrome 打开 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `D:\livebot` 文件夹
6. 打开 `https://live.douyin.com/*` 任意直播间即可看到左侧浮动按钮

## 使用

### 免费版

- 点击左侧 LiveBot 浮动按钮打开控制面板
- 开启「自动点赞」：设置每分钟点赞频率范围
- 开启「自动评论」：输入1条模板评论文字，每60秒自动发送一次

### VIP 会员

- 免费版全部功能 +
- 模板评论间隔可调，支持多达50条评论模板（随机/顺序/智能去重）
- AI 智能评论：选择人设（买家/粉丝/路人/老手/小白），AI 自动分析直播间内容生成弹幕

## 授权激活

1. 点击控制面板顶部的 `VIP` 徽章进入会员中心
2. 复制你的**机器码**发送给管理员
3. 管理员生成授权 Key 后，粘贴到输入框点击激活
4. 激活成功后 VIP 功能即时生效
5. 授权 Key 同时显示在会员中心面板中，可点击复制以便备份

常见问题
Q：扩展安全吗？ A：扩展仅在抖音直播间页面运行，不收集任何个人信息，不影响账号安全。
Q：会被抖音封号吗？ A：评论间隔和频率均可自定义，建议设置合理间隔，模拟真实用户行为。
Q：支持哪些浏览器？ A：目前支持 Chrome 及基于 Chromium 内核的浏览器（Edge、360极速浏览器等）。
Q：VIP到期后怎么续费？ A：到期后扩展会提示"已过期请联系开发者"，扫描弹窗中的微信二维码联系续费即可。
